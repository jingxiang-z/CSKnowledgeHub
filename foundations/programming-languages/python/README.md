# Python Essentials

Learn the Python needed to understand the foundation examples. These ten short chapters follow the core topics of the [official Python tutorial](https://docs.python.org/3/tutorial/), with focused additions from the standard library documentation. Each chapter includes an example and references.

## Learning Path

| Chapter | What you will learn | Official starting point |
|---|---|---|
| [01 Getting Started and Environments](01-getting-started-and-environments.md) | interpreter, scripts, virtual environments, and dependencies | Tutorial: interpreter; virtual environments |
| [02 Values and Control Flow](02-values-and-control-flow.md) | dynamic types, expressions, branches, and loops | Tutorial: introduction; control flow |
| [03 Collections, References, and Copying](03-collections-references-and-copying.md) | lists, tuples, dictionaries, sets, and shared objects | Tutorial: data structures |
| [04 Functions and Scope](04-functions-and-scope.md) | parameters, return values, defaults, and closures | Tutorial: defining functions |
| [05 Modules and Packages](05-modules-and-packages.md) | imports, package layout, and entry points | Tutorial: modules |
| [06 Exceptions and Cleanup](06-exceptions-and-cleanup.md) | raising, catching, chaining, and context managers | Tutorial: errors and exceptions |
| [07 Files and the Standard Library](07-files-and-the-standard-library.md) | paths, text, JSON, and argument parsing | Tutorial: input/output; standard library |
| [08 Classes and Type Hints](08-classes-and-type-hints.md) | methods, instance state, dataclasses, and protocols | Tutorial: classes; typing documentation |
| [09 Iterators and Generators](09-iterators-and-generators.md) | iteration, comprehensions, lazy evaluation, and yield | Tutorial: iterators and generators |
| [10 Tests and Tooling](10-tests-and-tooling.md) | unittest, discovery, diagnostics, and style | Standard library: unittest; PEP 8 |

Read in order the first time. Examples use Python 3.10 or later and only the standard library. Python code blocks are standalone scripts unless file names indicate a package or a test layout. The setup chapter uses POSIX shell commands; on Windows, the interpreter launcher and environment activation command may differ.

## Scope and Further Reading

This path covers small programs and the semantics needed to read systems exercises. Async programming, threading, multiprocessing, descriptors, metaclasses, and distribution publishing can wait until a project needs them. Consult the official tutorial and library documentation for those extensions.

Return to [Programming Language Foundations](../README.md) for the other language guides.
