# Programming Language Exercises

Each subdirectory contains one implementation exercise and one `README.md` describing its goal and completion criteria. Implement an exercise in Rust, Go, Python, or C++; use the matching programming-language note as a reference rather than copying a solution.

| Exercise | Focus |
|---|---|
| [01-record-analyzer](01-record-analyzer) | fundamentals: types, collections, control flow, functions |
| [02-library-catalog](02-library-catalog) | data modeling, methods, and invariants |
| [03-checkout-model](03-checkout-model) | composition and variants |
| [04-data-access-semantics](04-data-access-semantics) | copies, aliases, mutation, and views |
