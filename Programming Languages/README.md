# Programming Languages

This section compares the same programming-language concepts in Rust, Go, Python, and C++. Read the chapters in order when learning the material for the first time, or use the concept tables at the end of each chapter as a quick reference.

## Practice

The [programming-language exercises](examples/README.md) turn the early chapters into small implementation tasks. Complete an exercise in one language, then repeat it in another and explain which differences are syntactic and which reflect different language semantics.

## Scope

These notes emphasize practical language concepts rather than compiler construction. Parsing, abstract syntax trees, interpreters, compiler passes, and formal operational semantics are natural follow-on topics, but are outside the current learning path.
