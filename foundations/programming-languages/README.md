# Programming Language Foundations

Choose a language-specific guide for the foundations needed to understand systems code. Each guide covers essential concepts using that language's syntax, semantics, and tools. Read the chapters in your chosen guide in order.

## Language-Specific Learning Paths

- [Rust essentials](rust/README.md): ten short beginner chapters covering core syntax, ownership, types, modules, collections, errors, traits, lifetimes, tests, and iterators.
- [Go essentials](go/README.md): ten short beginner chapters covering modules, syntax, structs, collections, interfaces, errors, generics, concurrency, cancellation, and tests.
- [Python essentials](python/README.md): ten short beginner chapters covering syntax, collections, functions, modules, exceptions, files, classes, typing, generators, and tests.
- [C++ essentials](cpp/README.md): ten short beginner chapters covering builds, syntax, classes, lifetimes, containers, errors, ownership, templates, algorithms, and tests.
